# Web-Based Billing System for Small Retail Stores

## Project Overview

This project is being developed as part of the Bachelor of Computer Applications (BCA) program at Manipal University Jaipur.

The objective of this project is to develop a web-based billing system that helps small retail stores manage inventory, generate bills, maintain customer records, and track sales efficiently.
